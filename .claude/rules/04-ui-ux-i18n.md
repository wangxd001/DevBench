# UI、响应式、国际化与无障碍规则

## 视觉与交互
整体方向为“极简专业 + 现代科技感”：信息层级清晰、操作直接、突出输入与结果、避免复杂装饰和无意义动画。主色方向低饱和蓝色，具体色值统一由 Design Tokens 管理。支持浅色与深色主题。

工具页面基本包含名称、简短说明、输入、必要参数、操作按钮、结果、错误/状态提示、可折叠说明、相关工具。输入和结果分离，结果不得覆盖原始输入。空输入不应产生误导错误；非法输入应有明确提示；长任务需有处理中状态；结果区域不能无限撑高。

统一能力按工具需要提供清空、复制、下载、处理中、错误、空结果、超限提示和长结果滚动/折叠。不是每个工具都必须支持下载。

## 响应式
- 桌面：侧边栏导航；工具页面优先左右布局；编辑器/结果区有合理尺寸。
- 平板：按可用宽度调整。
- 移动端：移动导航或抽屉；工具默认上下布局；触控控件易用；无明显横向溢出。
- JSON Diff 和文本 Diff 必须专门适配移动端，不能直接缩小桌面双栏。

## 国际化
支持 `zh-CN`、`en-US`，默认简体中文。页面标题、导航、工具名称/说明、按钮、标签、参数、错误/成功/空/加载状态、使用说明、隐私说明和快捷键提示都必须双语完整。JWT、JSON、UUID、Base64 等技术术语可保留英文。

## 搜索与导航
全局搜索覆盖中英文名称、别名、关键词、描述和标签；大小写不敏感，支持中英文混合，按相关性排序；数据来自注册中心。快捷键 Windows/Linux `Ctrl+K`，macOS `Cmd+K`，用于聚焦搜索框。无结果时给出明确提示和目录入口。

收藏与置顶语义独立。最近使用最多 10 个；成功进入工具页后记录，预加载和搜索结果展示不记录。清空最近使用不影响收藏/置顶。

## 无障碍
目标 WCAG 2.2 AA：
- 核心操作支持键盘；Tab 顺序合理；Enter/Space/Esc 符合预期；
- 焦点清晰可见；文本对比充分；
- 输入有标签，图标按钮有可访问名称；
- 弹窗正确管理焦点；
- 错误和状态可被辅助技术感知；
- 使用语义结构；
- 不只依赖颜色表达状态，尤其 Diff。
自动扫描不能替代人工键盘与辅助技术检查。
