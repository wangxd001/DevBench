# 安全、隐私与数据处理规则（最高优先级）

## 本地处理
用户输入和处理结果默认只在浏览器本地处理。产品不得主动上传或发送用户输入/结果到服务器、第三方 API、分析服务或远程日志。

允许的网络请求仅限应用必要静态资源，以及用户主动访问外部链接。核心工具不得依赖外部 API/CDN。

## 禁止存储与泄露
以下数据不得写入任何持久化存储或可持久化位置：
- 用户输入、处理结果；
- JWT、Cookie、Authorization Header、Token、密码、业务数据及其他敏感内容。

禁止位置包括：
- LocalStorage、SessionStorage、IndexedDB；
- URL 查询参数、路径、浏览器历史；
- Service Worker Cache；
- 应用日志、控制台日志；
- Zustand 或其他全局 Store；
- 任何遥测、错误报告或第三方服务。

工具输入和结果只存在于当前页面局部运行状态。刷新、关闭或离开页面后不恢复。

LocalStorage 仅可保存 PRD 明确允许的非敏感偏好：主题、语言、收藏、置顶、最近使用、少量非敏感工具偏好。读取/写入异常不能影响核心功能，也不能触发上传回退。

## 敏感数据专项
对 JWT、Cookie、Authorization Header、Token、密码和业务数据，必须检查：
- 是否进入全局 Store；
- 是否写入任何存储；
- 是否出现在 URL、日志、控制台或缓存；
- 是否被任何网络请求发送。

不得声称可验证地物理擦除 JavaScript 内存。离开页面后释放局部状态即可按 PRD 实施。

## HTML 与注入
- 不执行用户输入。
- HTML 实体解码结果按纯文本展示。
- 不把用户输入或解码后的 HTML 注入可执行 DOM。
- 避免 `dangerouslySetInnerHTML`；不得用其渲染不可信输入。
- 避免不必要第三方脚本。

## 网络与仓库
- 配置合理 CSP，限制外部脚本来源。
- 不提交 API Key、Token、密码、私钥或其他秘密。
- `.env.example` 只能有变量名和非敏感示例值。
- 隐私说明准确描述本地处理和静态资源请求元数据，不得承诺“绝对安全”。

## 隐私验证
不能只通过搜索代码中是否存在 fetch/上传函数判断合规。测试需检查实际请求 URL、查询参数、请求头、请求体，以及存储、控制台、日志和 Service Worker Cache。
